# Knota

**A General-Purpose AI-Based Skill Assessment and Learner Modelling Framework**

Knota is an experimental framework for estimating what a learner
actually understands and can apply.

Rather than modelling learning primarily as flashcard completion,
Knota represents learner state using assessment evidence across
concepts, cognitive levels, question formats, difficulty, and time.

## Status

Knota is currently an experimental concept and prototype.
The learner models described in this repository include research
hypotheses that have not yet been empirically validated.

## Core Research Question

Can a shared learner model generalise across users and heterogeneous
knowledge domains?
